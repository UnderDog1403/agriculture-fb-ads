# Frameworks Overview

This directory contains the core frameworks for generating high-converting Facebook Ads.

## Available Frameworks

| Framework | File | Purpose |
|-----------|------|---------|
| Hooks | `hooks.md` | Attention-grabbing opening lines |
| Angles | `angles.md` | Ad angle templates by emotional trigger |
| Copy Formulas | `copy-formulas.md` | Proven copy structures (PAS, AIDA, etc.) |
| Video Script Formulas | `video-scripts-formula.md` | Video script structures and formulas |

## How to Use

1. **Select Hook**: Choose based on audience state (cold/warm/hot)
2. **Pick Angle**: Match to emotional trigger (frustration, hope, trust)
3. **Apply Formula**: Use based on video length and platform
4. **Build Creative**: Follow template for visual direction

## Quick Selection Guide

```
Cold Audience → Curiosity Hook + Pain Point Angle + PAS Formula
Warm Audience → Statistic Hook + Social Proof Angle + AIDA Formula
Hot Audience → Urgency Hook + Transformation Angle + Direct Benefit
```

## Customization

- Mix and match hooks with angles
- Adapt formulas to your brand voice
- Test 2-3 variations per ad set
- Update hooks monthly based on performance
