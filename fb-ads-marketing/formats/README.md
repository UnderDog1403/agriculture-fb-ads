# Formats Overview

Facebook ad format specifications.

## Available Formats

| Format | File | Use Case |
|--------|------|----------|
| Video | `video.md` | Dynamic, engaging content |

## Format Selection Guide

| Goal | Best Format |
|------|-------------|
| Brand awareness | Video (15-30s) |
| Engagement | Video (10-15s) |
| Conversions | Video (30-60s) |
| Product demo | Video (30-60s) |
| Testimonial | Video (15-20s) |

## Quick Specs

### Video Ads

| Placement | Aspect Ratio | Duration | Resolution |
|-----------|--------------|----------|------------|
| Feed | 1:1 or 16:9 | 1-180s | 1080x1080 / 1920x1080 |
| Reels | 9:16 | 15-60s | 1080x1920 |
| Stories | 9:16 | 1-15s | 1080x1920 |
| In-stream | 16:9 | 5-120s | 1920x1080 |

## Best Practices

1. **Design for sound-off**: Add captions/text overlays
2. **Front-load key content**: Hook in first 3 seconds
3. **Match placement**: Vertical for Reels/Stories, square for Feed
4. **Keep it short**: Shorter videos often perform better
5. **Brand early**: Show logo/brand in first 5 seconds
