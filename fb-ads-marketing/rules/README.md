## Quick Compliance Checklist

Before launching any ad, verify:

- [ ] No personal attributes in ad text
- [ ] No before/after images (health/weight)
- [ ] No discriminatory targeting
- [ ] No misleading claims
- [ ] Landing page matches ad content
- [ ] No prohibited content categories
- [ ] Proper disclaimers included
- [ ] All claims are substantiated

## Common Violations

| Violation | Example | Fix |
|-----------|---------|-----|
| Personal attributes | "Are you a single mom?" | "For single parents" |
| Before/after | Weight loss photos | Use testimonial quotes |
| Discrimination | Exclude races/religions | Remove exclusions |
| Misleading claims | "Guaranteed results" | "Results may vary" |
